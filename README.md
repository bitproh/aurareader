# AuraReader — Offline Neural Audiobook & E-Reader

AuraReader is a desktop PDF and EPUB e-reader with **human-like neural text-to-speech**, automatic reading progress tracking ("continue where you stopped last"), interactive highlights & annotations, and offline chapter summarization.

---

## 🌟 Key Features

### 1. Gapless, Natural Narration Pipeline
- **Zero-Stutter Lookahead Prebuffering**: Proactively synthesizes 3-4 sentences ahead into memory so the audio stream never runs dry.
- **Continuous Hardware Streaming**: Uses a persistent `sounddevice.OutputStream` that streams audio chunks directly to your speakers without stopping and re-initializing the audio driver between sentences.
- **Dead-Air & Silence Trimming**: Strips artificial silence generated by TTS models and applies a smooth micro-fade with a configurable natural pause.
- **Adjustable Sentence Gap**: Choose your preferred pacing right from the toolbar:
  - `0.04s (Tight)`: Fast, seamless flow with minimal pause.
  - `0.08s (Natural)`: Recommended default human cadence.
  - `0.15s (Standard)`: Clear, punctuated pause.
  - `0.25s (Relaxed)`: Slower, contemplative study pacing.

### 2. Dual TTS Engines
- **🎙️ Kokoro (100% Offline Neural)**: Multi-threaded ONNX CPU inference (optimized with 6 cores) for rich, human-like cadence and offline privacy.
- **⚡ Edge-TTS (Fast Neural)**: Real-time studio voices (Christopher, Jenny, Guy, Sonia) with 0 delay and zero CPU load.

### 3. Live Spoken Sentence Highlighting
- Visually tracks narration in real time by highlighting the active spoken sentence with a warm background and auto-scrolling to keep it centered in view.
- Click any sentence or right-click to **"Read from here"** to start listening from any spot.

### 4. Continue Where You Left Off (Auto-Resume)
- Remembers your exact book, chapter, paragraph, and sentence position automatically in SQLite.
- Re-opening any book seamlessly resumes reading right where you stopped.

### 5. Interactive Highlights & Notes
- Select any text with your mouse to:
  - Highlight in 🟡 Yellow, 🟢 Green, 🔵 Blue, or 🟣 Pink.
  - Attach personal study notes / annotations.
  - View all saved highlights in the **⭐ Highlights** sidebar tab (click any highlight to jump directly to it).

### 6. Offline Chapter & Selection Summarizer
- Powered by **TextRank / LexRank** extractive summarization.
- Generates instant key takeaways in concise bullet points with **0 API keys**, **0 cloud dependencies**, and **0 seconds latency**.
- Summarize either the full active chapter or any highlighted selection from the right-click menu.

### 7. Reader Customization
- **Themes**: Dark Charcoal, Warm Sepia, and Modern Light.
- **Font Scaling**: Instant `A-` and `A+` font size controls.
- **Navigation**: Table of Contents, Chapters, and Bookmarks.

## 🚀 How to Run

Launch the application using either:

```bash
python main.py
```
or
```bash

```
